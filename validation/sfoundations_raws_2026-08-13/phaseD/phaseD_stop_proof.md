## §2 The equivariance half [T-T0P-E]

### §2.1 The group and its action

The problem's symmetry group is G_full := SO(2)_theta x R_t, acting
on fields by rigid rotation about e_x combined with time translation.
For phi in R and tau in R define, on any field q = (rho, u, S-etc.)
over Omega x R:

    (g_{phi,tau} q)(x, X_perp, t) := R_phi [ q(x, R_{-phi} X_perp,
                                              t - tau) ],          (ACT)

where X_perp = (y, z), R_phi is the rotation by phi of the transverse
plane, and R_phi[.] acts on the state componentwise: scalars
(rho, S, p, e) unchanged, the velocity vector by (v, w) ->
R_phi (v, w), u unchanged. In cylindrical components
(rho, u_x, u_r, u_theta, S) the action is the pure shift
(theta, t) -> (theta - phi, t - tau), componentwise.

The HELICAL SUBGROUP selected by the data speed OM is the
one-parameter group

    g_tau := g_{OM tau, tau},   tau in R,                        (HEL)

together with the discrete rotation rho_n := g_{2pi/n, 0}.

[L-EQV1] LEMMA (rotation equivariance of Euler). THEOREM. Let R be a
rotation about e_x and q a weak solution of (EU) on Omega x R (H1).
Then q^R defined by (ACT) with tau = 0 is a weak solution of (EU) on
(R Omega) x R = Omega x R.
PROOF. Frame-indifference by direct substitution in the weak form.
Let phi_test be a test function and phi_test^R its rotation. The
fluxes of (EU) transform covariantly under the orthogonal map
R with det R = 1: mass and energy components are scalars,
momentum components a vector; explicitly, writing
F(W) . grad phi := F_x d_x phi + F_y d_y phi + F_z d_z phi, one has
for every state:  F(R W) . grad(phi_test o R^{-1})  evaluated at
R X  equals  R applied to [ F(W) . grad phi_test ] at X in the sense
that the scalar mass/energy rows coincide and the momentum rows are
the R-image — an elementary computation from the dyadic structure
rho u (x) u + p Id of the momentum flux (R (rho u (x) u + p Id) R^T
= rho (Ru)(x)(Ru) + p Id) and rho u H -> rho (Ru) H for the energy
row. The change of variables X -> R X in each integral of the weak
form (|det R| = 1) then maps the weak formulation for q exactly onto
the weak formulation for q^R. The EOS enters only through
p = p(rho, S), a rotational scalar: ABSTRACT EOS, gamma(T) included.
QED.

[L-EQV2] LEMMA (time-shift equivariance). THEOREM. (EU) is
autonomous; if q is a weak solution on Omega x R so is
q(., . , . - tau). PROOF: immediate (coefficients t-independent;
change of variables in the weak form). QED.

[L-EQV3] LEMMA (class preservation — RESTATED for the FULL group in
revision 1 per l1-F6). THEOREM. Under H1-H9, for EVERY
(phi, tau) in G_full the map g_{phi,tau} of (ACT) maps the solution
class of H6'/H7' with inflow data s onto the solution class with
inflow data g_{phi,tau} s. Specifically g_{phi,tau} preserves:
 (i)   weak-solution property (L-EQV1 + L-EQV2);
 (ii)  the slip BC and the wall set (Gamma_w is rotation-invariant

### §2.2 Invariance implies steadiness

[L-STD] LEMMA (steadification of an invariant field — proof
COMPLETED in revision 1 per l0-F6/l1-F7). THEOREM.
Let q in L^inf(Omega x R) satisfy q = g_tau q a.e. on Omega x R for
EVERY tau in R (g_tau as in (HEL)). Then there exists
q_tilde in L^inf(Omega) (a function of (x, r, theta') alone) with

    q(x, r, theta, t) = q_tilde(x, r, theta - OM t)   a.e.,      (STD)

i.e. q is a STEADY pattern in the frame co-rotating at OM. If
moreover q is continuous off a null set N with g_tau N = N for
every tau, (STD) holds POINTWISE off N. (Hypothesis WEAKENED in
revision 3 per l1's F9 / r2-F11: the round-1 clause required N
CLOSED, which the named application cannot supply — the essential
discontinuity set is an F_sigma, and for an S1 field it is a
relatively open subset of the front sheets, generically NOT closed
where a front dies out; the repaired proof below consumes no
topology of N at all.)
PROOF. Pass to co-rotating coordinates: define
Q(x, r, theta', t) := q(x, r, theta' + OM t, t) — measurable, since
the map Phi(x,r,theta',t) = (x,r,theta'+OM t,t) is a bi-Lipschitz
measure-preserving bijection. The hypothesis reads: for every tau,
Q(., t) = Q(., t - tau) a.e. (computed: (g_tau q)(theta'+OM t, t)
= q(theta' + OM t - OM tau, t - tau) = Q(theta', t - tau) since
theta' + OM t - OM tau = theta' + OM(t - tau) + 0), with the
exceptional null set N_tau in general DEPENDING ON tau (an
uncountable family — the point this lemma exists to handle).
Mollify in t only: Q_eps := Q *_t rho_eps with rho_eps a standard
mollifier. Fix tau: the a.e. identity survives convolution exactly,
so by Fubini there is a SPATIAL null set E_tau (in the (x,r,theta')
variables) off which Q_eps(X, t) = Q_eps(X, t - tau) for ALL t
(both sides are continuous in t). COUNTABLE-DENSE CLOSURE (the step
the round-0 draft skipped): let D subset R be countable and dense,
and E := Union_{tau in D} E_tau — still spatially null. For X off
E, the continuous function t -> Q_eps(X, t) is invariant under all
translations by elements of D, hence constant on each dense orbit
t - D, hence CONSTANT on R by continuity. (Irrational-vs-rational
tau needs no separate case: density of D suffices.) So
Q_eps(., t) = Q_eps(., 0) for all t, a.e. in space. EPS-SEQUENCE
BOOKKEEPING (one sentence, written per r2-F11(b) — the exceptional
spatial set E = E^(eps) depends on eps): fix a countable sequence
eps_n -> 0 and take the union of the E^(eps_n), still spatially
null, off which the constancy holds for every n. As eps_n -> 0,
Q_eps_n -> Q in L^1_loc, so Q(., t) = Q_bar a.e. for a.e. t with
Q_bar := L^1_loc-lim Q_eps_n(., 0), independent of t (and of the
chosen sequence, by uniqueness of L^1_loc limits). Undoing Phi
gives (STD) with q_tilde = Q_bar.
Pointwise refinement, and DISCHARGE OF THE INVARIANCE HYPOTHESIS
g_tau N = N for the application (the round-0 draft consumed it
unproven): take N to be the ESSENTIAL discontinuity set of q — the
complement of the set of points at which the precise representative
of the a.e.-class is continuous. N is an invariant of the
a.e.-equivalence class; since g_tau is a bi-Lipschitz bijection
preserving the measure class and q = g_tau q a.e., it maps the
class of q to itself, hence g_tau N = N for every tau. For an S1
representative (H6'), N is contained in the front set AFTER
EXCISION of zero-jump sheets (a front sheet across which the jump
vanishes is a removable discontinuity of the representative: the
piecewise-C^1 function extends continuously there, so such sheets
are not in the essential set); genuine fronts have nonzero jump on

needed. POINTWISE CONCLUSION without any topology of N (repaired

QED.

## §3 The x-as-time structure of the UNSTEADY problem

The in-house uniqueness machinery ([T-XWS]) is written for the
STEADY planar 2-D system. The statement of [T-T0P] needs uniqueness

not proven). This section extends the four bricks. The x-as-time
reading survives because the L4 margin makes {x = const} spacelike

[L-SPACE] LEMMA (unsteady spacelikeness of axial slices — RE-SCOPED
in revision 1 per l1-F5/l0-F11: the lemma states what its proof
reaches; the determinacy reading is moved to the Remark below and
attributed to its actual proof). THEOREM. At every state in K
(H5'): every characteristic of (EU) crosses {x = const}
transversally in the +x direction: along every bicharacteristic,
dx/dt in [u - c, u + c] union {u}, hence dx/dt >= u - c >= delta
> 0 on K. Consequently:
 (i)  surfaces {x = const} are noncharacteristic and spacelike for
      (EU) on K-valued fields, so x is a legitimate evolution
      variable;
 (ii) in the x-evolution reading with transverse variables
      (y, z, t), the transverse slopes dy/dx, dz/dx, dt/dx of every
      bicharacteristic are uniformly bounded on K (since dx/dt is
      bounded below by delta and the spatial speeds are bounded on
      the compact K);

      {x = 0} = Gamma_d in a compact set.

backward ray segment, reflected or not, loses x at rate >= delta

transverse extent. QED.
