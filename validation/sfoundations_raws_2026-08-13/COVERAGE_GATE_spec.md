# COVERAGE GATE — closing gate of S-FOUNDATIONS (user mandate 2026-08-17)

User order (verbatim intent): at the end of the agnostic phase and of
ALL workflows there must be a COMPLETE-COVERAGE CHECK — that every
point of the developed edifice (every hypothesis, method, modeling/
mathematical sub-problem) has been re-examined, re-derived and
re-confronted with the possible SOTA branchings for its specific
sub-problem. This gate BLOCKS the R3 close: the session does not
close green without it.

## Structure (arithmetic first, critic second — both required)

### (A) MACHINE INVENTORY (the denominator)
Assembled by script/greps, never from memory:
1. HYPOTHESES: the problem-statement hypothesis table (I-GEO, I-STATE,
   H-DATA, R1, R2/L4, R3, GAS, CORE, J_EX, AMB, GEOM, S1) — 12 items.
2. CHOICES: all 49 choice-ledger rows.
3. THEORY CLAIMS: the claims-registry theorem inventory (lint (xv)
   list) — the load-bearing statements of M0/D-docs.
4. DE-NOVO FORKS: the 141 Phase-A forks (4 condensed tables).
5. NOVEL ITEMS: the 16 Phase-B §2 items + hypothesis-audit bundles
   (6) + contract-blind demands (from the workflow verdicts).

### (B) THREE-WAY COVERAGE ACCOUNTING (the rejector)
For EVERY inventory item, exactly one of:
- COVERED(anchor): re-derived / confronted / adjudicated in THIS
  session — with the anchor (tree fork, diff §, workflow verdict
  file, ledger/registry row updated);
- PARTIAL(named): touched but not closed — the missing half NAMED
  with owner+trigger (a typed row, never prose);
- NOT-COVERED: = a FINDING, seeded as a registry row in the closing
  window, first duty of the next window.
Arithmetic reconciled to zero: |inventory| == covered + partial +
not-covered, per category, written in the session log.

### (C) ADVERSARIAL COMPLETENESS CRITIC (the blind spot hunter)
One dedicated agent (Fable), AFTER (B) is drafted, with the mandate:
"what is MISSING from this coverage matrix itself — an edifice point
not in the inventory, a modality not run, a hypothesis confronted
only from one lens, a SOTA branch family absent from every
alternatives set?" — with DUAL-SEED (one planted inventory omission
it must find; one fully-covered item it must not flag). Critic
findings feed back into (B)'s accounting before the gate verdict.

### (D) GATE VERDICT
PASS = arithmetic at zero + critic dry (no unaccounted omission) +
dual-seed proven. Anything else = the session closes with the gate
verdict RED declared in PROGRESS (never silently green).

## Standing consequence (beyond this session)
This gate is the session-level analogue of the S-ORDINE NOTHING-LOST
gate applied to THEORY coverage; candidate for standing adoption at
every future theory window (record at R3 close; user ratification at
the next touchpoint).
