## 0. Gas model and standing hypotheses

**Thermally-perfect frozen gas.** Fixed (frozen) composition, single effective gas constant
R > 0; thermal equation of state p = rho R T; caloric equation of state e = e(T)
(internal energy a function of temperature alone), with

- c_v(T) := e'(T),  c_p(T) := c_v(T) + R,  gamma(T) := c_p(T)/c_v(T).

**Standing gas hypotheses (G):**

- (G1) R > 0 constant (frozen composition — the [T-T3] Lemma A thermal pin of record, M0);
- (G2) e in C^2 on the working temperature interval [T_min, T_max], with
  0 < c_v,min <= c_v(T) <= c_v,max; hence 1 < gamma(T) <= gamma_max < infinity and
  gamma(T) - 1 = R/c_v(T) >= R/c_v,max > 0;
- (G2') **(global clause; class PRACTICE; used ONLY where explicitly invoked)**: the (G2) bounds
  hold on [T_min, infinity) and (G4) below holds globally along Hugoniot arcs. This is an
  extrapolation beyond the tabulated backend's validity, and it is PHYSICALLY superseded at large
  post-shock temperatures (dissociation breaks the frozen thermally-perfect model — memory pin
  `scope-pins-frozen-thermally-perfect`). Every statement below is therefore given in a capped
  in-box form under (G2)-(G4) alone, with the unbounded form conditional on (G2'). See NG-6.
- (G3) state box: rho in [rho_min, rho_max], T in [T_min, T_max], with rho_min, T_min > 0. All
  constants below depend only on these bounds (and the base-state norms named per theorem).
- (G4) (used ONLY in Theorem 3, parts B2-B3) fundamental derivative
  Gamma_fund := 1 + (rho/c) (dc/drho)_s >= Gamma_min > 0 on the working box (globally under
  (G2')). Lemma 3.1 computes Gamma_fund exactly for this gas class:
  Gamma_fund = (gamma+1)/2 + (gamma-1) T gamma'(T) / (2 gamma),
  so (G4) is a checkable table condition, automatic when |T gamma'(T)| is small (gamma = const
  gives the textbook (gamma+1)/2).

**Lemma 0.1 (entropy and sound speed for gamma(T)). THEOREM.**
Under (G1)-(G3) the gas admits a specific entropy s with
T ds = de - (p/rho^2) drho, explicitly s(T, rho) = Int_{T_ref}^{T} c_v(t)/t dt - R ln(rho/rho_ref),
and the isentropic sound speed satisfies

    c^2 := (dp/drho)_s = gamma(T) R T > 0.

*Proof.* Existence of s: the 1-form (1/T) de - (R/rho) drho = c_v(T) dT/T - R drho/rho is exact
(closed with separated variables), giving the stated s; ds = 0 along a path means
c_v dT/T = R drho/rho. Then along an isentrope,
dp = d(rho R T) = R T drho + rho R dT = R T drho + rho R (R T/c_v) (drho/rho)
= R T (1 + R/c_v) drho = gamma(T) R T drho. Positivity from (G2)-(G3). QED.

*gamma(T) status*: exact for the class; no gamma-const step. *Falsifier*: symbolic/numeric check of
(dp/drho)_s − gamma R T on random (T, rho) draws with a tabulated c_v(T) (numpy, pinned env);
rejects if any residual exceeds derived roundoff bound.

**Lemma 0.2 (primitive form and full 3-D eigenstructure). THEOREM.**
Smooth solutions of compressible Euler (mass, momentum, energy with E = e(T) + |u|^2/2) satisfy,
under (G1)-(G3), the primitive quasilinear system in V = (rho, u, p) in R^5:

    rho_t + u . grad rho + rho div u            = 0
    u_t   + (u . grad) u + (1/rho) grad p       = 0
    p_t   + u . grad p   + rho c^2 div u        = 0,   c^2 = gamma(T) R T,  T = p/(rho R).

For a unit vector n, the directional Jacobian

    A(n) = [ u.n      rho n^T        0        ]
           [ 0        (u.n) I_3      n/rho    ]
           [ 0        rho c^2 n^T    u.n      ]

has characteristic polynomial det(A(n) - lambda I) = (u.n - lambda)^3 [ (u.n - lambda)^2 - c^2 ],
hence eigenvalues and multiplicities (3-D):

    lambda_- = u.n - c   (simple; acoustic, incoming-side),
    lambda_0 = u.n       (multiplicity 3: one ENTROPY mode + two SHEAR/VORTICITY modes),
    lambda_+ = u.n + c   (simple; acoustic).

Right eigenvectors (t_1, t_2 any orthonormal basis of n^perp):
r_- = (rho, -c n, rho c^2)^T ... precisely r_∓ = (rho, ∓ c n, rho c^2)^T for lambda_∓ = u.n ∓ c;
entropy mode r_s = (1, 0, 0)^T (density at fixed pressure, i.e., an entropy perturbation);
shear modes r_{t_i} = (0, t_i, 0)^T, i = 1, 2. The eigenvalue u.n is semisimple (3 independent
eigenvectors); A(n) is diagonalizable whenever c > 0.

*Proof.* Derivation of the p-equation: with e = e(T), the energy equation for smooth flow reduces
to c_v(T) DT/Dt = -(p/rho) div u = -R T div u (D/Dt = material derivative), so
Dp/Dt = R T Drho/Dt + rho R DT/Dt = -rho R T (1 + R/c_v) div u = -gamma p div u = -rho c^2 div u
by Lemma 0.1. The determinant: expand det(A(n) - lambda I) along the first column: the (rho)-row
couples only forward, giving factor (u.n - lambda) times the 4x4 acoustic block
det( [(u.n - lambda) I_3, n/rho; rho c^2 n^T, u.n - lambda] )
= (u.n - lambda)^2 [ (u.n - lambda)^2 - c^2 ] (Schur complement: the rank-one coupling
(n/rho)(rho c^2 n^T) = c^2 n n^T has eigenvalues c^2, 0, 0). *(r1, continuity step made explicit:
the Schur-complement identity requires u.n - lambda != 0; both sides of the resulting determinant
identity are polynomials in lambda, so the identity extends to lambda = u.n by continuity of
polynomials.)* Eigenvectors by direct substitution. QED.

*gamma(T) status*: verbatim; only c = c(T) enters. *Falsifier*: numeric eigendecomposition of A(n)
on random admissible states/directions vs the closed forms; rejects on eigenvalue mismatch above
roundoff or on defective multiplicity (rank test of A - (u.n) I must give rank 2).

    U^(1) = U^(2)  on  Omega_up x [0, T_f].

### 1.2 Linearized system and the characteristic variable

Write V = V-bar + V', V' = (rho', u', p'). Substituting into Lemma 0.2's system and keeping first
order:

    rho'_t + u-bar . grad rho' + rho-bar div u'  = g_rho[V'; grad W-bar]
    u'_t   + (u-bar . grad) u' + grad p'/rho-bar = g_u[V'; grad W-bar]     (LIN)
    p'_t   + u-bar . grad p'  + rho-bar c-bar^2 div u' = g_p[V'; grad W-bar]

where every g_* is a ZEROTH-order expression in V' with coefficients that are products of
base-state values and first derivatives of W-bar — hence in L^infinity by (H1.1), (G2)-(G3)
(explicitly: g_rho = -u'.grad rho-bar - rho' div u-bar, g_u = -(u'.grad) u-bar
+ (rho'/rho-bar^2) grad p-bar, g_p = -u'.grad p-bar - (rho c^2)'|_lin div u-bar, where
(rho c^2)'|_lin is a fixed linear combination of (rho', p') with (G)-bounded coefficients since
rho c^2 = gamma(T) p and T = p/(rho R)).

**Characteristic (entropy) variable.** Set sigma := rho' - p' / c-bar^2 and U := (sigma, u', p').
Subtracting (1/c-bar^2) x (p'-equation) from the (rho')-equation kills the div u' coupling at
principal level:

    sigma_t + u-bar . grad sigma                    = b_sigma . U
    u'_t + (u-bar.grad) u' + grad p'/rho-bar        = b_u . U               (LIN-U)
    p'_t + u-bar.grad p' + rho-bar c-bar^2 div u'   = b_p . U

with L^infinity zeroth-order matrices b_* (the variable change contributes terms in
grad(1/c-bar^2), bounded by (H1.1) and (G2)). The principal part of (LIN-U) is block
lower-triangular — in fact block-diagonal: a scalar transport for sigma and a 4x4 acoustic block
for (u', p'):

    U_t + Sum_j A_j(W-bar) d_j U + B U = F,
    A_j = [ u-bar_j   0            0            ]
          [ 0         u-bar_j I_3  e_j/rho-bar  ]
          [ 0         rho-bar c-bar^2 e_j^T  u-bar_j ],
    B in L^infinity(Omega x [0,T_f]; R^{5x5}).

By Lemma 0.2 (block form), spec A(n) = { u-bar.n - c-bar, u-bar.n (x3), u-bar.n + c-bar } with the
same multiplicities as before (sigma = entropy mode + 2 shear modes at u-bar.n).

### 1.3 Friedrichs symmetrizer

Define

    S := diag( kappa, rho-bar I_3, 1/(rho-bar c-bar^2) ),   kappa := c-bar^2 / rho-bar  (any
    kappa with (G)-uniform positive bounds works; this choice normalizes the entropy mode).

**Lemma 1.1 (symmetrization). THEOREM.** S = S^T, and by (G2)-(G3) there are constants
0 < s_min <= s_max with s_min I <= S <= s_max I on Omega x [0,T_f]. For every unit n,
S A(n) is symmetric:

    S A(n) = (u-bar . n) S + [ 0    0    0  ]
                              [ 0    0    n  ]
                              [ 0    n^T  0  ],

hence the boundary quadratic form is

### 1.4 Energy identity and proof of Theorem 1

Let U := U^(1) - U^(2) on Omega_up x [0, T_f]. Since (LIN-U) is linear with coefficients depending
only on W-bar, U solves U_t + Sum A_j d_j U + B U = 0 on Omega_up (the forcings cancel there by
hypothesis), with U(., 0) = 0 on Omega_up, U = 0 on Gamma_in, u-component-normal = 0 on Gamma_w.
Note that U^(1), U^(2) are solutions on all of Omega; we restrict to Omega_up, where Gamma_I
is part of the boundary with outward normal n_I — and use NO information from downstream.

Define E(t) := Int_{Omega_up} <S U, U> dx. Using U in C^1, S, SA_j Lipschitz (by (H1.1), (G2)),
and the symmetry of every S A_j (Lemma 1.1):

    2 <S U, A_j d_j U> = d_j <S A_j U, U> - <(d_j (S A_j)) U, U>,

so

    dE/dt = Int_{Omega_up} < (d_t S + Sum_j d_j(S A_j) - 2 sym(S B)) U, U > dx
            - Int_{del Omega_up} <S A(n) U, U> dsigma.                    (EI)

The volume matrix is in L^infinity with a bound C_0 = C_0(||W-bar||_{W^{1,infinity}}, G-bounds)
(this is where (H1.1) is load-bearing), so the volume term is <= C_0 E(t) (using S >= s_min I to
compare |U|^2 with <SU, U>). Boundary decomposition:

- Gamma_in: U = 0 => integrand 0.
- Gamma_w: 0 by Lemma 1.3.
- Interface Gamma_I (n = n_I, a.e. defined): by (H1.3) + Lemma 1.2 pointwise a.e.,
  -Int_{Gamma_I} <S A(n_I) U, U> <= - delta Int_{Gamma_I} <S U, U> <= 0.   (OUTFLOW-DISSIPATION)

Hence dE/dt <= C_0 E(t), E(0) = 0, and Gronwall gives E == 0 on [0, T_f]; since S >= s_min I > 0,
U == 0 on Omega_up x [0, T_f]. This proves the claim; (OUTFLOW-DISSIPATION) is the quantitative
outgoing-flux statement (rate >= delta x boundary energy). **QED (Theorem 1).**
