    A(n) = [ u.n      rho n^T        0        ]

### 1.1 Statement

**Hypotheses.**
- (H1.1) Base state W-bar = (rho-bar, u-bar, p-bar) in W^{1,infinity}(Omega x [0, T_f]),
  values in the (G3) box; c-bar^2 = gamma(T-bar) R T-bar (Lemma 0.1). (The base state need not be
  an exact Euler solution; if it is not, the linearization residual is absorbed in the forcing f.)
- (H1.2) Slip walls: u-bar . n = 0 on Gamma_w; linearized perturbations satisfy u' . n = 0 on
  Gamma_w (fixed rigid wall).
- (H1.3) **L4 margin (the certificate), NORMAL form (r1)**:
  u-bar(x, t) . n_I(x) - c-bar(x, t) >= delta > 0 for a.e. x in Gamma_I and all t in [0, T_f]
  (for the stability remark 1.5.1, on the slab S_h with n_I extended along the transversal
  foliation). On a planar patch this is exactly the recorded axial form u-bar_x - c-bar >= delta.
  **On a tilted patch the axial form does NOT imply the normal form** (u_x - c >= delta allows
  u.n_I < c when n_I tilts away from e_1); the certificate consumed by this theorem is the normal
  one. See NG-8 for the M0 wording item.
- (H1.4) Solutions: perturbations U in C^1(closure(Omega) x [0, T_f]; R^5) solving the linearized
  system below; by density the estimate extends to
  U in C([0, T_f]; H^1(Omega)) intersect C^1([0, T_f]; L^2(Omega)) (remark 1.5.3, under (D'')).

**Claim.** Let U^(1), U^(2) be two solutions of the linearized Euler system (same base state, same
forcing f on Omega_up) such that

  (i) U^(1) = U^(2) at t = 0 on Omega_up,
  (ii) U^(1) = U^(2) on the inflow face Gamma_in for t in [0, T_f]  (see (ii') in Remark 1.5.5 for
       the physically-posed incoming-data variant),

and **no condition whatsoever** is imposed at the interface Gamma_I or anywhere downstream (the
two solutions, their data, and even their forcing may differ arbitrarily on
Omega \ Omega_up). Then

    U^(1) = U^(2)  on  Omega_up x [0, T_f].

Moreover the interface is a **pure-outflow boundary** for Omega_up: the boundary matrix A(n_I)
there has all five eigenvalues >= delta (spectrum {u-bar.n_I - c-bar, u-bar.n_I (x3),
u-bar.n_I + c-bar}, Lemma 0.2), the symmetrized boundary form obeys S A(n_I) >= delta S > 0, no
boundary condition is admissible or needed on Gamma_I for the upstream problem, and the energy
flux through the interface is outgoing with rate at least delta times the boundary energy density.

**Rigor class: THEOREM (complete proof below).**
**gamma(T) status: fully general** — the proof uses only c-bar^2 = gamma(T-bar) R T-bar > 0 and the
(G) bounds; no step assumes gamma constant.

### 1.2 Linearized system and the characteristic variable

Write V = V-bar + V', V' = (rho', u', p'). Substituting into Lemma 0.2's system and keeping first
order:

    rho'_t + u-bar . grad rho' + rho-bar div u'  = g_rho[V'; grad W-bar]
    u'_t   + (u-bar . grad) u' + grad p'/rho-bar = g_u[V'; grad W-bar]     (LIN)
    p'_t   + u-bar . grad p'  + rho-bar c-bar^2 div u' = g_p[V'; grad W-bar]

where every g_* is a ZEROTH-order expression in V' with coefficients that are products of
base-state values and first derivatives of W-bar — hence in L^infinity by (H1.1), (G2)-(G3)
(explicitly: g_rho = -u'.grad rho-bar - rho' div u-bar, g_u = -(u'.grad) u-bar
+ (rho'/rho-bar^2) grad p-bar, g_p = -u'.grad p-bar - (rho c^2)'|_lin div u-bar, where
(rho c^2)'|_lin is a fixed linear combination of (rho', p') with (G)-bounded coefficients since
rho c^2 = gamma(T) p and T = p/(rho R)).

**Characteristic (entropy) variable.** Set sigma := rho' - p' / c-bar^2 and U := (sigma, u', p').
Subtracting (1/c-bar^2) x (p'-equation) from the (rho')-equation kills the div u' coupling at
principal level:

    sigma_t + u-bar . grad sigma                    = b_sigma . U
    u'_t + (u-bar.grad) u' + grad p'/rho-bar        = b_u . U               (LIN-U)
    p'_t + u-bar.grad p' + rho-bar c-bar^2 div u'   = b_p . U

with L^infinity zeroth-order matrices b_* (the variable change contributes terms in
grad(1/c-bar^2), bounded by (H1.1) and (G2)). The principal part of (LIN-U) is block
lower-triangular — in fact block-diagonal: a scalar transport for sigma and a 4x4 acoustic block
for (u', p'):

    U_t + Sum_j A_j(W-bar) d_j U + B U = F,
    A_j = [ u-bar_j   0            0            ]
          [ 0         u-bar_j I_3  e_j/rho-bar  ]
          [ 0         rho-bar c-bar^2 e_j^T  u-bar_j ],
    B in L^infinity(Omega x [0,T_f]; R^{5x5}).

By Lemma 0.2 (block form), spec A(n) = { u-bar.n - c-bar, u-bar.n (x3), u-bar.n + c-bar } with the
same multiplicities as before (sigma = entropy mode + 2 shear modes at u-bar.n).

### 1.3 Friedrichs symmetrizer

Define

    S := diag( kappa, rho-bar I_3, 1/(rho-bar c-bar^2) ),   kappa := c-bar^2 / rho-bar  (any
    kappa with (G)-uniform positive bounds works; this choice normalizes the entropy mode).

**Lemma 1.1 (symmetrization). THEOREM.** S = S^T, and by (G2)-(G3) there are constants
0 < s_min <= s_max with s_min I <= S <= s_max I on Omega x [0,T_f]. For every unit n,
S A(n) is symmetric:

    S A(n) = (u-bar . n) S + [ 0    0    0  ]
                              [ 0    0    n  ]
                              [ 0    n^T  0  ],

hence the boundary quadratic form is

    <S A(n) U, U> = (u-bar.n) <S U, U> + 2 p' (u'.n).           (BQ)

*Proof.* Direct computation: S times the off-diagonal blocks of A(n) gives
rho-bar (n/rho-bar) = n (u'-row) and (1/(rho-bar c-bar^2)) rho-bar c-bar^2 n^T = n^T (p'-row);
the diagonal advection part is (u-bar.n) S, symmetric. QED.

**Lemma 1.2 (margin => uniform positivity of the boundary matrix; valid for EVERY unit n).
THEOREM.** If u-bar.n - c-bar >= delta at a point, then at that point

    S A(n) >= delta S    (as quadratic forms).

*Proof.* N := S^{1/2} A(n) S^{-1/2} = S^{-1/2} (S A(n)) S^{-1/2} is symmetric (Lemma 1.1) and
similar to A(n), so spec N = spec A(n) = { u-bar.n - c-bar, u-bar.n, u-bar.n + c-bar } subset
[delta, infinity) (Lemma 0.2 + hypothesis). A symmetric matrix with spectrum >= delta satisfies
N >= delta I; conjugating back, S A(n) = S^{1/2} N S^{1/2} >= delta S. QED.

This is the precise sense in which the interface is **pure outflow**: with outward normal n_I for
Omega_up, ALL characteristic speeds on Gamma_I are >= delta > 0 — the two acoustic modes
(u.n_I ± c >= delta and >= delta + 2c), the entropy mode and both shear modes (u.n_I >= delta + c).
The incoming-characteristic count on Gamma_I is ZERO; by the Friedrichs theory of admissible
(maximal nonnegative) boundary subspaces, the only admissible boundary condition there is the
trivial one — none.

**Lemma 1.3 (wall annihilation). THEOREM.** On Gamma_w (u-bar.n = 0, u'.n = 0), <S A(n) U, U> = 0.
*Proof.* Immediate from (BQ). QED.

### 1.4 Energy identity and proof of Theorem 1

Let U := U^(1) - U^(2) on Omega_up x [0, T_f]. Since (LIN-U) is linear with coefficients depending
only on W-bar, U solves U_t + Sum A_j d_j U + B U = 0 on Omega_up (the forcings cancel there by
hypothesis), with U(., 0) = 0 on Omega_up, U = 0 on Gamma_in, u-component-normal = 0 on Gamma_w.
Note that U^(1), U^(2) are solutions on all of Omega; we restrict to Omega_up, where Gamma_I
is part of the boundary with outward normal n_I — and use NO information from downstream.

Define E(t) := Int_{Omega_up} <S U, U> dx. Using U in C^1, S, SA_j Lipschitz (by (H1.1), (G2)),
and the symmetry of every S A_j (Lemma 1.1):

    2 <S U, A_j d_j U> = d_j <S A_j U, U> - <(d_j (S A_j)) U, U>,

so

    dE/dt = Int_{Omega_up} < (d_t S + Sum_j d_j(S A_j) - 2 sym(S B)) U, U > dx
            - Int_{del Omega_up} <S A(n) U, U> dsigma.                    (EI)

The volume matrix is in L^infinity with a bound C_0 = C_0(||W-bar||_{W^{1,infinity}}, G-bounds)
(this is where (H1.1) is load-bearing), so the volume term is <= C_0 E(t) (using S >= s_min I to
compare |U|^2 with <SU, U>). Boundary decomposition:

- Gamma_in: U = 0 => integrand 0.
- Gamma_w: 0 by Lemma 1.3.
- Interface Gamma_I (n = n_I, a.e. defined): by (H1.3) + Lemma 1.2 pointwise a.e.,
  -Int_{Gamma_I} <S A(n_I) U, U> <= - delta Int_{Gamma_I} <S U, U> <= 0.   (OUTFLOW-DISSIPATION)

Hence dE/dt <= C_0 E(t), E(0) = 0, and Gronwall gives E == 0 on [0, T_f]; since S >= s_min I > 0,
U == 0 on Omega_up x [0, T_f]. This proves the claim; (OUTFLOW-DISSIPATION) is the quantitative
outgoing-flux statement (rate >= delta x boundary energy). **QED (Theorem 1).**

### 1.5 Remarks

**1.5.1 (Why the margin, not mere supersonicity).** With delta = 0 the interface term is only
<= 0 pointwise where u.n_I > c and degenerates on {u.n_I = c} (glancing set); the uniform delta
makes the outflow property stable under the W^{1,infinity} perturbations of the base state actually
present in the certified pipeline, and makes (OUTFLOW-DISSIPATION) quantitative. This is exactly
why the L4 default is stated WITH margin (M0 [D-CONTRACT], "per-phase spacelikeness margin").

**1.5.2 (Finite speed of propagation) — r2 PROMOTED from SCHEMA to a proved lemma (it becomes
load-bearing for Proposition 1'' in Section 1.6; the promotion is R2-O2's own demand).**

**Lemma 1.4 (finite speed, W^{1,infinity} coefficients). THEOREM.** Let O be an open subset of
Omega on which W-bar is W^{1,infinity} with (G3)-box values, and set
lambda_max := sup_O (|u-bar| + c-bar). Let U be a C^1 solution of the homogeneous (LIN-U) on O
and suppose U(., t_0) = 0 on B(x_0, R) intersect O, where the frustum
F := { (x, t) : t_0 <= t <= t_1, |x - x_0| <= R - lambda_max (t - t_0) } meets del O only in
wall portions (Gamma_w) or margin interface portions (Gamma_I with (H1.3)). Then U == 0 on
F intersect (closure(O) x [t_0, t_1]).
*Proof.* Let F_t := B(x_0, R - lambda_max (t - t_0)) intersect O and
E(t) := Int_{F_t} <S U, U> dx. Differentiating the shrinking-domain energy and applying (EI)'s
algebra on F_t:

    dE/dt = [volume term <= C_0 E]
            - Int_{del F_t^sph} [ lambda_max <S U, U> + <S A(nu_sph) U, U> ] dsigma
            - Int_{del F_t intersect del O} <S A(n) U, U> dsigma,

where del F_t^sph is the shrinking spherical part with outward unit normal nu_sph (the
lambda_max <S U, U> term is the domain-shrinkage flux). The spherical integrand is >= 0 because
lambda_max S + S A(nu) >= 0 for EVERY unit nu: by the Lemma 1.2 similarity argument
spec A(nu) subset [u-bar.nu - c-bar, u-bar.nu + c-bar] subset [-lambda_max, lambda_max], so
S^{1/2} (lambda_max I + N) S^{1/2} >= 0 with N as in Lemma 1.2. The del O portions contribute
>= 0 (zero on walls by Lemma 1.3; >= 0 on margin interface portions by Lemma 1.2). Hence
dE/dt <= C_0 E with E(t_0) = 0, and Gronwall gives E == 0 on [t_0, t_1]. QED.
Influence therefore propagates at speed <= lambda_max on every W^{1,infinity} region — the
statement r1 carried as SCHEMA, now proved with the document's own symmetrizer (consistent with
the standard references: Benzoni-Gavage & Serre Ch. 1-2; Friedrichs 1954; Rauch, *Hyperbolic
PDEs and Geometric Optics* Ch. 2 — cited for context, no longer load-bearing). *Falsifier*:
numeric cone test — localized initial pulse in a margin base; the numerical support at time t
must stay inside radius R + (lambda_max + C h^q) t with the excess shrinking under refinement; a
non-shrinking excess rejects (scheme or lemma).
