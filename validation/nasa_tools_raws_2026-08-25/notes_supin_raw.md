## Pages 1-30 (front matter, §1 Introduction, §2.1-2.5)

- Bibliographic: J. W. Slater, "SUPIN: A Tool for the Aerodynamic Design and Analysis of Supersonic Inlets", NASA/TM-20240008586, October 2024, NASA Glenn Research Center. 302 pp. Sponsored by Advanced Air Vehicles Program. Companion earlier paper: Slater AIAA 2016-0532 (Ref 26 of §1).
- Abstract (p.1): SUPIN = Fortran 95 batch/non-interactive tool; inlet types: axisymmetric pitot, 3D pitot, axisymmetric spike, 2D single-duct, 2D bifurcated-duct, streamline-traced. Flowpath split into components freestream→engine face: external supersonic diffuser, throat section, subsonic diffuser. Input factors (geometric: angles, lengths, area ratios, coords; aerodynamic: Mach, flow ratios, pressure ratios) in text input file. Analytic + empirical + numerical methods. Geometry as planar/3D constructs; Plot3D surface grid output; some automated multi-block structured CFD grid generation. Quasi-1D aero analysis through flowpath; planar shock/Mach-wave computations for external supersonic diffuser + throat section. Performance = flow rates, total pressure recovery, inlet drag.
- Nomenclature (pp.2-5): gamma = 1.4 for air; R = 1716.246 lbf-ft/slug-°R (nomenclature) vs 1716.235 in Eq. section p.26 (minor internal inconsistency). Subscripts: 0 freestream, 1 cowl lip, 2 engine face, TH throat, EX end external compression, IN end internal compression, SD start subsonic diffuser, NS downstream normal/terminal shock, CP calorically perfect, TP thermally perfect.
- §1.1 (pp.6-9): inlet role, missions (transport/attack/missile/accelerator), engines (turbojet, turbofan, ramjet, scramjet, rocket, combined cycles: turbo-ramjet, DMRJ, TBCC, RBCC). Engine-face throttle behavior: turbojet/turbofan raising throttle lowers engine-face static pressure; ramjet/scramjet opposite (p.9). Mach 5 limit on document scope (dissociation avoided) p.7.
- §1.3-1.4 pitot inlets history (pp.10-14): normal-shock recoveries quoted: M1.3→0.979 (M_ds 0.786), M1.6→0.895 (0.668), M2.0→0.721 (0.557) (p.14). F-16 pitot inlet M2 recovery ~0.72.
- §1.5 external compression (pp.14-17): Taylor-Maccoll (Ref 12, 1933) and Busemann (Ref 13, 1942) conical methods. Example recoveries (p.14-15): M1.6: single 8.5° ramp + NS at M1.3 → 0.972; 21.6° half-angle cone + NS → 0.974. M2.0: 18.26° ramp + NS → 0.899; 30.76° cone + NS → 0.906. Trommsdorff ramjet projectile (1940s Germany); Ferri & Nucci NACA TR-1104 (1952) axisymmetric spike terminal-shock schematic (Fig 1.3, p.15). Terminal shock = normal shock or shock train (forms when M ahead of terminal shock well above ~1.3, separation-induced oblique train) p.16. Key: external-compression terminal shock at cowl lip allows subsonic spillage → inherent stability. External compression preferred M1.4-2.2 (p.16). Concorde 2D external-compression inlet with strong near-oblique shock + wide bleed slot behaving like internal compression (Ref 19, 20) p.17.
- §1.6 mixed compression (pp.18-20): internal supersonic diffuser; terminal shock in throat section; isolator for scramjet (shock train isolating combustor); SR-71 (axisym, translating spike), XB-70 (2D, hinged ramps); inlet starting problem, unstart; bleed/bypass stability systems. Streamline-traced mixed-compression via Busemann flowfields (Refs 23-25) for hypersonic.
- §1.7 SUPIN overview (pp.20-21): execution seconds to ~1 min per inlet. Available via NASA Software Catalog, US persons only. Purpose: geometry for CFD + rapid design/analysis.
- §1.8 roadmap (pp.21-22). References list p.22-23 (Taylor-Maccoll Ref12; Busemann Ref13; Oswatitsch NACA TM-1140 Ref15; Ferri-Nucci Ref16; Mahoney "Inlets for Supersonic Missiles" Ref17; Concorde Candel Ref19, Slater AIAA 2020-3770 Ref20; Otto/Trefny/Slater JPP 2016 streamline-traced Ref21; Mölder-Szpiro Busemann Ref23; Van Wie-Mölder Ref24; Billig et al. Ref25; Slater AIAA 2016-0532 Ref26).
- §2.1-2.2 (p.24): inlet flowpath = streamtube freestream→engine face; control volume; Cartesian frame fixed to inlet, x toward engine face, plane of symmetry x-y; Eulerian.
- §2.3 Air models (pp.25-29): US Standard Atmosphere (Ref 2) with standard/cold/hot days, curve fits. Perfect gas p = ρRT (Eq 2-1). R = 1716.235 ft-lbf/slug-°R (p.26). M=V/a, a=sqrt(γRT) (2-2,2-3), q=γpM²/2 (2-4). Isentropic total T, p (2-5, 2-6). Calorically perfect: cp=6006.823, cv=4290.588 lbf-ft/slug-°R, γ=1.4, below ~1800°R (1000K). Thermally perfect above: cp_TP(T) = cp_CP{1+((γ-1)/γ)[(Θ/T)² e^{Θ/T}/(e^{Θ/T}-1)²]} (2-12), similarly cv (2-13), Θ=5500°R vibrational constant (planck harmonic oscillator). γ_TP ≡ cp_TP/cv_TP (2-14), drops from 1.4 starting ~600°R to ~1.30 at M6-class temps (Fig 2.4 p.28). Dissociation onset ~4500°R (2500K) > temps for M≤6 inlets, so only CP/TP models. Entropy change Eq 2-10 (constant cp). Average-specific-heats approach for conceptual design (Ref 5 Heiser-Pratt) p.29. Inlets estimated temps ≤ ~3500°R at M6 (Fig 2.3, p.26); temps insensitive to dynamic pressure choice 300-2000 psf.
- §2.4 Quasi-1D representation (p.29): uniform average properties at stations; acknowledges nonuniform segments (external supersonic diffuser, internal oblique-shock regions) — quasi-1D only asserted at select stations.
- §2.5 Components and stations (pp.29-30): SAE AS 755 station numbering: 0 freestream, L local (non-standard, ahead of inlet start), 1 cowl lip, 2 engine face; ramjet/scramjet: station 3 = combustor start (Fig 2.6). Components: approach flow (0→L), external supersonic diffuser (L→1), internal diffuser (1→2 or 1→3) comprising internal supersonic diffuser, throat section, subsonic diffuser, isolator.

## Pages 31-50 (§2.5.1-2.11, §3.1-3.5)

- §2.5.1 (p.31): pitot inlets: no external supersonic diffuser; internal diffuser = throat section + subsonic diffuser; stations TH (geometric throat = min area) and SD (start subsonic diffuser) are SUPIN additions, not SAE AS 755. Quasi-1D applicable at TH, SD. Placement of SD somewhat arbitrary design choice.
- §2.5.2 (pp.31-33): external-compression inlets: terminal shock about station 1; station TS = shoulder (surface slope along inlet axis; flow redirects toward axis/engine). Stations EX (end of external supersonic compression, upstream side of terminal shock) and NS (just downstream of terminal shock); terminal shock modeled in SUPIN as a NORMAL shock, infinitesimally thin → EX and NS collocated (p.33). Shock-wave-train possibility for M0>3 external-compression: train may extend into throat section (p.33).
- §2.5.4 (p.34): mixed-compression: internal supersonic diffuser between 1 and TH (TH at end of internal contraction); throat section TH→SD contains terminal shock system; station IN = end of internal supersonic compression upstream of terminal shock; NS downstream. If shock train, IN and NS bracket a segment. Throat length sized to contain terminal-shock motion range.
- §2.5.5 (p.34): DMRJ/scramjet: isolator TH→3, near-constant-area duct, oblique shock train; isolates from combustor unsteadiness.
- Table 2.1 (p.35): station list: 0, L, EX, NS, 1, TS, TH, IN, SD, 2, 3.
- §2.6 (p.35-36): flow rate W = ρAV = p A M sqrt(γ/(RT)) = (pt A/sqrt(Tt)) φ (2-15); flow function φ = M sqrt(γ/R) (1+(γ-1)/2 M²)^{-(γ+1)/(2(γ-1))} (2-16), max at M=1 (Fig 2.13). Assumes γ const + adiabatic in this discussion. Units slug/s or lbm/s.
- §2.7 (p.36-37): reference capture flow rate W_cap = A_cap p_tL φ_L / sqrt(T_tL) (2-17); A_cap = forward projection of highlight trace along x; = undisturbed streamtube area reaching highlight. 2D: A_cap = w_cap h_cap; axisym spike: A_cap = π y_clip².
- §2.8 (p.37-38): corrected engine flow W_C2 = W2 sqrt(θ2)/δ2 = p_tref A2 φ2/sqrt(T_tref) (2-18); θ2 = Tt2/Ttref, δ2 = pt2/ptref (2-19); Ttref = 518.69 °R, ptref = 2116.2 psf = 14.696 psi. Note: specifying M2 ≡ specifying W_C2 for given A2, γ, R. Engine flow ratio = W2/W_cap (2-20).
- §2.9 (pp.38-41): flow bookkeeping: W_L inlet capture flow rate (2-21); inlet capture flow ratio = W_L/W_cap = A_L/A_cap (2-22); full flow = unity; supersonic: ≤1 only. Spillage W_spillage = W_cap − W_L (2-23); subsonic vs supersonic spillage definitions (terminal shock ahead of cowl lip → subsonic spillage; oblique-system streamline deflection → supersonic spillage). Design practice: allow small supersonic spillage margin (p.40). Bleed components by station interval: W_bL1, W_b1SD, W_b1TS (sidewall), W_b1TH, W_bTHSD, W_bSD2, W_bTH3 (isolator); totals per inlet type Eqs 2-24/25/26. Bypass W_bypass extracted between SD and 2 (doors); other flow W_other (cooling, leakage, auxiliary injection; ± sign) assumed between SD and 2 (or TH and 3).
- §2.10 (p.42-43): flow balance: W_L/W_cap + W_spill/W_cap = 1 (2-27); W2 = W_L − W_bleed − W_bypass − W_other (2-28); inlet flow balance equation W2/W_cap = 1 − Σ ratios (2-29) → used for SIZING A_cap from known W2. Streamtube continuity pt2 A2 φ2/… = pt1 A1 φ1 (2-30, adiabatic → Tt cancels); Eq 2-31a/b/c: solve for M2 (iterate φ), area, or total pressure ratio given the others. "Equation (2-31) encapsulates the basic relationships between Mach number, area, and total pressure that are central to inlet design and analysis." Station-interval continuity with bleed (2-32a-d).
- §2.11 (pp.43-44): critical/subcritical/supercritical operation; external-compression: terminal shock at lip = critical; subcritical → shock ahead, subsonic spillage; supercritical → shock swallowed, lower pt2. Mixed-compression: terminal shock within throat section; too subcritical → shock forced upstream of TH → unstart. Fig 2.18/2.19 CFD Mach contours (M_L=1.6 ext-comp; Mach 3 mixed-comp with bleed rates quoted: crit W2/Wcap=0.9229, Wbleed/Wcap=7.17%; subcrit 0.8654/12.87%).
- §3.1 (p.46): inlet total pressure recovery = pt2/ptL (3-1), mass-averaged at engine face. Product decomposition across components: ext-comp (3-2): ptEX/ptL × ptNS/ptEX × pt1/ptNS × ptSD/pt1 × pt2/ptSD; mixed-comp (3-3): ptEX/ptL × pt1/ptEX × ptTH/pt1 × ptIN/ptTH × ptNS/ptIN × ptSD/ptNS × pt2/ptSD.
- §3.2 (pp.46-48): characteristic "cane curve": recovery vs engine flow ratio; supercritical leg vertical (choked, constant flow ratio) for no-bleed ext-comp; critical point = knee = max recovery at max flow; subcritical leg ~constant recovery w/ decreasing flow ratio (spillage); buzz limit (ext-comp), unstart limit (mixed-comp) marked (Fig 3.1). Eq 3-4: line of constant corrected flow through origin; slope ∝ 1/W_C2 — operating point = intersection with characteristic curve.
- §3.3 (p.48-49): MIL-E-5007E military standard recovery (Eq 3-5): pt2/ptL = 1.0 for M≤1; = 1 − 0.075(M_L−1)^1.35 for 1<M<5; = 800/(M_L^4+935) for M>5. NOTE: text calls it MIL-E-5007E here (§3.3); table Fig 3.2 values: M1.3→0.985, 1.5→0.971, 1.6→0.962, 1.7→0.954, 2.0→0.925, 2.5→0.870, 3.0→0.809, 3.5→0.742, 4.0→0.669, 5.0→0.513, 6.0→0.359. (User prompt said MIL-E-5008B; the TM cites MIL-E-5007E.)
- §3.4 (pp.49-50): distortion metrics: Min-Max distortion (3-6); SAE ARP 1420 ring-based DPC/P, DPR/P indices w/ 40-probe rake (8 rakes × 5 probes at equal-area centroids); hub vs tip distortion; GE IDC/IDR; DC(60) (3-7). Rules of thumb: DPC/P<0.1, DPR/P<0.1, IDC<0.2, IDR<0.1.
- §3.5 (p.50): static pressure ratio p2/pL (3-8).

## Pages 51-60 (§3.6-3.11, §4.0-4.4)

- §3.6 (p.51): static temperature ratio ψ = T3/TL (3-9); ramjet/scramjet limit T3max = 2800 °R (1560 K) (Ref 5 Heiser-Pratt) to avoid dissociation/combustor limits.
- §3.7 (p.51-52): engine-face Mach: turbine 0.3<M2<0.6; ramjet M3 subsonic; scramjet M3>1; rule of thumb M3/M0 = sqrt(T0/T3) ≈ sqrt(400/2800) ≈ 0.38 (3-10); supersonic combustion possible starting M3≈6.4 → hypersonic needs scramjet.
- §3.8 (p.52-53): contraction ratios: CRg = A_cap/A_TH (3-11), CR_eff = A_L/A_TH (3-12), CR_int = A1/A_TH (3-13); for ext-comp use A1 instead of A_TH. External/internal compression split ratios: (A_L−A1)/(A_L−A_TH) and (A1−A_TH)/(A_L−A_TH) (3-14/3-15); "55-45 inlet" nomenclature (Bowditch NASA TM X-71460 Ref 6).
- §3.9 (p.53-54): adiabatic compression efficiency η_C = (h3−hx)/(h3−hL) (3-16), hx = isentropic re-expansion to pL; h-s diagram Fig 3.4; assumes calorically perfect with average cp_c, γ_c (3-17); η_C = (ψ−Tx/TL)/(ψ−1) (3-18).
- §3.10 (p.54): kinetic energy efficiency η_KE = (h_t3−h_X)/(h_tL−h_L) (3-19) = Vx²/VL² (3-20); Vx² = VL² −2Cpc(TL−Tx) (3-21); relations to η_C (3-22) and to total pressure ratio (3-23): η_KE = 1 − 2/((γc−1)ML²) {(ptL/pt2)^((γc−1)/γc) −1}. η_KE preferred in hypersonics (freestream-referenced). Heat transfer ΔQ/mdot = h_tL − h_t3 (3-24); adiabatic form (3-25).
- §3.11 (p.55): incompressible flow ratio η_σi = (p_tf − p_L)/(p_tL − p_L) (3-26) for subsonic. Refs: MIL-E-5007E (Sept 1983); SAE ARP 1420 Rev C 2017; SAE AIR 1419 Rev C 2017; Moore AFAPL-TR-72-111; Heiser-Pratt; Bowditch TM X-71460.
- §4.0-4.1 (p.56): SUPIN developed by Inlets and Nozzles Branch, NASA Glenn. Self-contained (no external libs), Windows/Unix/Mac, Fortran 95. Input SUPIN.in → output SUPIN.Out.txt (ASCII). Surface grid SUPIN.xyz (Plot3D). Multi-block structured CFD grids for some inlets; ~30M grid points → couple of minutes execution. Mostly analytic; planar-geometry assumptions for oblique shocks and MoC.
- §4.2 (pp.56-58): input data file structure: title block (3 lines) + input data blocks identified by DataID. Table 4.1 (p.57) DataID list: 0 Main control; 1 Freestream; 2 Approach flow; 3 Capture cross-section (placeholder/not functional); 4 External supersonic diffuser; 5 Uniform cowl lip; 6 Cowl exterior; 7 3D cowl lip; 8 Throat section; 9 Support struts; 10 Subsonic diffuser; 11 Engine face; 12 Bleed and bypass; 13 Flow domain and grid spacing; 14 Variations; 15 Shoulder bleed slot; 16 Components and entities; 17 Geometry transformations; 18 Variable geometry; 19 Schedules; 21 Inlet surface grid input (red); 22 Vortex generators (red); 23 Unit problem calculations; 24 Reference dimension; 25 Forebody step diverter; 26 Forebody geometry model; 27 Sidewall geometry (red); 28 Auxiliary intake (red); 29 Global geometry transformations; 30 Output summary table; 31 3D engine face (red). (Red italic = placeholders not fully functional.) Lengths normalized by reference dimension (nominally engine-face diameter); angles in degrees. After execution writes SUPIN.new.in with updated factors (calculated lengths/angles) — restart/design-iteration mechanism.
- §4.3 (pp.58-60): Kmode: 0 = Unit Problem Mode (standalone aero calcs, e.g. cone flow, normal shock); 1 = Inlet Geometry Mode (explicit geometry; area distributions; no aero performance) — only pitot/axisym-spike/2D, not streamline-traced; 2 = Inlet Design Mode (sizing+design at design point; performance computed); 3 = Inlet Analysis Mode (given geometry → performance at off-design; STILL BEING DEVELOPED, NOT FULLY FUNCTIONAL — stated in red); 4 = Inlet Flowpath Analysis Mode (quasi-1D streamtube: area, pt, Mach only). Ktyp (Table 4.3): 0 generic quasi-1D; 1 axisym pitot; 2 two-dimensional; 3 axisym spike; 4 2D bifurcated; 5 streamline-traced; 6 3D pitot. Kcomp (Table 4.4): 0 subsonic; 1 external-compression; 2 mixed-compression subsonic outflow; 3 mixed-compression supersonic outflow (isolator, DMRJ/scramjet). Design mode assumes ext-comp inlet at critical point with specified supersonic spillage; mixed-comp: terminal shock between TH and SD.

Supersonic inlets: essentially sharp lips via b_clin ≈ 0.0001 ft. Axisym: profiles revolved; 2D: linear extrusion in z over capture width; streamline-traced: supersonic segment + subsonic segment w/ blending; 3D pitot: profile dimensions vary along circumference.
