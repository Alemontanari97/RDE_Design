## 1. Bibliographic identity, purpose, architecture

- **Identity**: John W. Slater (Inlets and Nozzles Branch, NASA Glenn Research Center), *SUPIN: A Tool for the Aerodynamic Design and Analysis of Supersonic Inlets*, NASA/TM-20240008586, October 2024, 302 pp. Distribution via the NASA Software Catalog, US persons only (p.21). Supersedes/extends the AIAA 2016-0532 SUPIN paper.
- **Purpose** (Abstract p.1; §1.7 pp.20-21): rapid (seconds to ~1 minute) aerodynamic **design** (sizing + geometry generation) and **analysis** (performance estimation) of supersonic inlets for Mach 0.6–5, plus automated generation of surface grids and multi-block structured CFD grids so that higher-fidelity CFD verification is a push-button continuation of the low-order design.
- **Implementation**: self-contained Fortran 95 batch code, no external libraries, ASCII input file `SUPIN.in` structured in DataID blocks, primary output `SUPIN.Out.txt` (§4.1-4.2, pp.56-58).
- **Inlet types** (Ktyp, Table 4.3 p.60): axisymmetric pitot, 3D pitot, two-dimensional single-duct, two-dimensional bifurcated-duct, axisymmetric spike, streamline-traced (STEX); plus a generic quasi-1D flowpath type.
- **Compression types** (Kcomp, Table 4.4 p.60): subsonic, external compression, mixed compression with subsonic outflow, mixed compression with supersonic outflow (isolator, for ramjet/scramjet/DMRJ).
- **Modes** (Kmode, §4.3 pp.58-60): 0 = Unit Problem Mode (standalone gasdynamics calculators: cone flow, shock tables, Prandtl-Meyer, Moeckel stand-off, atmosphere sweeps — Appendix H.3 pp.281-282); 1 = Inlet Geometry Mode (geometry + areas only); 2 = **Inlet Design Mode** (sizing + design at the design point, the primary mode); 3 = Inlet Analysis Mode (**explicitly flagged as still in development / not fully functional**, p.59); 4 = Inlet Flowpath Analysis Mode (quasi-1D Mach-area-recovery bookkeeping only, §4.16 pp.86-87).
- **Flowpath decomposition** (§2.5, pp.29-35): approach flow (station 0→L), external supersonic diffuser (L→1), internal supersonic diffuser (1→TH, mixed compression only), throat section (TH→SD, contains the terminal shock for mixed compression), subsonic diffuser (SD→2), isolator (TH→3 for scramjet). Station set (Table 2.1 p.35): 0, L, EX, NS, 1, TS (shoulder), TH, IN, SD, 2, 3 — SAE AS 755 augmented with SUPIN-specific stations (TH, SD, TS, EX, IN, NS).
- **Design philosophy**: quasi-1D bookkeeping at stations + planar (2D/axisymmetric) shock, Mach-wave and MOC computations for the supersonic diffusers; empirical loss correlations for everything viscous; geometry as chained analytic entities (lines, ellipses, super-ellipses, NURBS); everything normalized by the engine-face reference dimension D_ref so inlets scale with the engine (§4.14 pp.82-83).

## 2. Complete method inventory (with anchors)

### 2.1 Atmosphere and gas model (§2.3, pp.25-29)
- 1976 US Standard Atmosphere curve fits + cold/hot/tropical day profiles (Kfs/Katm, §4.6 pp.63-64).
- Perfect gas p = ρRT (2-1), R = 1716.235 ft·lbf/slug-°R (p.26; nomenclature p.4 says 1716.246 — internal inconsistency of the last digit). **Calorically perfect γ = 1.4** below ~1800 °R (cp = 6006.823, cv = 4290.588 lbf-ft/slug-°R); **thermally perfect above**: harmonic-oscillator vibrational cp(T) with Θ = 5500 °R, Eqs (2-12)-(2-14); γ_TP falls from 1.4 (below ~600 °R) toward ~1.30 at Mach-6-class total temperatures (Fig 2.4 p.28). Dissociation onset ~4500 °R deliberately above the M≤5-6 envelope, so no real-gas chemistry anywhere (pp.26-28). Practical computations in the tool are constant-γ; the thermally-perfect model exists for property evaluation and the report recommends the average-specific-heat approach of Heiser-Pratt for conceptual design (p.29).
- Isentropic total relations (2-5)/(2-6); entropy change (2-10); flow function φ(M) with maximum at M=1 (2-16, Fig 2.13 p.36).

### 2.2 Flow bookkeeping — the sizing algebra (§2.6-2.11, pp.35-44)
- W = pt·A·φ/√Tt (2-15). Reference capture flow W_cap from capture area A_cap = forward projection of the highlight (2-17).
- Corrected flow W_C2 (2-18)/(2-19) with Ttref = 518.69 °R, ptref = 2116.2 psf; specifying M2 ⇔ specifying W_C2 for fixed A2 (p.38).
- Flow balance: W_L/W_cap + W_spill/W_cap = 1 (2-27); W2 = W_L − W_bleed − W_bypass − W_other (2-28); combined sizing identity (2-29). Bleed decomposed per station interval (Eqs 2-24/25/26, Fig 2.15 p.41); bypass extracted between SD and 2.
- **The central design relation** (p.43): adiabatic streamtube continuity pt2 A2 φ2 = pt1 A1 φ1 (2-30), rearranged three ways (2-31a/b/c) to solve for Mach (iteratively through φ), area, or total-pressure ratio given the other two — "the basic relationships between Mach number, area, and total pressure that are central to inlet design and analysis". Interval forms with bleed (2-32a-d).
- Operation classes (§2.11 pp.43-45): critical/subcritical/supercritical; external compression spills subsonically ahead of the lip (stable), mixed compression unstarts if the terminal shock is pushed ahead of the throat.

### 2.3 Performance metrics (§3, pp.46-55)
- Recovery pt2/ptL (3-1) decomposed as a product over components: external compression (3-2), mixed compression (3-3) (p.46).
- **Characteristic "cane curve"** recovery vs engine flow ratio, with critical knee, vertical supercritical leg, subcritical leg, buzz/unstart limits (Fig 3.1 p.47); operating point = intersection with the constant-W_C2 line through the origin (3-4, p.48).
- **Military-standard recovery correlation** (§3.3 pp.48-49, Eq 3-5, cited to MIL-E-5007E, 1983 — the MIL-E-5008B-style recovery schedule): pt2/ptL = 1 − 0.075(M_L−1)^1.35 for 1<M<5; 800/(M^4+935) for M>5. Table Fig 3.2: M2.0→0.925, M3.0→0.809, M4.0→0.669, M5→0.513. Used as the **initial guess** of the design iteration (§4.4 p.62).
- Distortion (§3.4 pp.49-50): SAE ARP 1420 ring indices DPC/P, DPR/P with 40-probe rake; GE IDC/IDR; DC(60) (3-7); rules of thumb DPC/P<0.1, IDC<0.2, IDR<0.1. SUPIN does not compute distortion from its own models; the section is bookkeeping context.
- Compression efficiencies (§3.9-3.10 pp.53-54): adiabatic η_C (3-16)-(3-18) and kinetic-energy efficiency η_KE (3-19)-(3-23) with the closed form relating η_KE to total-pressure ratio; hypersonic community preference for η_KE noted. Contraction ratios CRg, CR_eff, CR_int and external/internal split percentages ("55-45 inlet", Bowditch) (§3.8, 3-11..3-15, pp.52-53). Ramjet static-temperature limit T3 ≤ 2800 °R and the M3/M0 ≈ √(T0/T3) rule (3-10, pp.51-52).

### 2.4 Oblique shocks, Prandtl-Meyer, Taylor-Maccoll (§7, pp.110-124)
- θ-β-M solved **in closed form**: sextic in sinβ (7-2) reduced to a cubic in sin²β solved trigonometrically (7-4)/(7-5) with weak-branch root selection — no iteration (p.111).
- Prandtl-Meyer ν(M) (7-18)-(7-20) for Mach waves and isentropic compression fans (p.114).
- **Taylor-Maccoll conical flow** (§7.2 pp.112-113): nondimensional V' = V/Vmax form (7-10)-(7-12); **inverse solution**: guess shock angle θS, RK4-integrate in decreasing θ until surface tangency V'_θ = 0 (7-15); post-shock initial data (7-16)/(7-17); per-ray arrays (M, δ) from shock to cone.
- **External supersonic diffuser construction** (§7.4-7.5 pp.115-121): 1-3 stages of ramps (2D) or cones (axisym); all stage waves aimed at **focal points** on the vertical through the cowl lip (7-21); shock-on-lip (Δy_focal = 0) gives zero supersonic spillage; deliberate focal-point offsets (Kfocal options 1-6, incl. option 6: compute the focal point from a prescribed supersonic-spillage fraction WRspill) buy robustness margin (pp.117-121). Matching conditions Kmtexd: match M_EX, static-pressure ratio, or flow angle at diffuser exit — mass-averaged over the EX surface for axisymmetric spikes (p.119-120).
- **Oswatitsch optimality** (§7.6 p.122): equal stage total-pressure ratios maximize multi-stage recovery (Oswatitsch NACA TM 1140); SUPIN **imposes it for 2D 2-3-stage diffusers via a carpet search** over ramp angles — an optimality criterion implemented by brute-force search, not variationally.
- **Isentropic (MOC-designed) second stage** (§7.7 pp.122-123): curved contour generating Mach waves focused on the cowl lip with a **linear Mach deceleration** prescribed at the focal point; contour recovered from the MOC net (see Appendix B); waveless straight third stage from the end slope. With isentropic stage the external losses reduce to the first-stage shock only (p.123).
- **External-diffuser loss model** (§7.9 p.123): pt ratio = product of stage-shock normal-component losses (7-28); **no viscous/boundary-layer loss modeled on the external diffuser** (stated).

### 2.5 Pitot inlets (§5-§6, pp.90-109)
- Cowl-lip design from a specified throat Mach: A_TH = A1 φ1/φ_TH (5-2), quarter-ellipse interior lip (§5.2 p.91). Throat + subsonic diffuser profiles = four-point NURBS with 1/3-rule interior control points (§5.3-5.4 pp.92-95).
- **Subsonic diffuser loss model** (§5.7 p.98) — the workhorse empirical loss, ported from IPAC (Barnhart NASA CR-204130), rooted in Henry-Wood-Wilbur NACA RM L56F05: Eq (5-3) (pt2/ptSD) = 1 − [K_D(1−A_SD/A2)² + K_O + K_F]·K_M·[1−(1+((γ−1)/2)M_SD²)^(−γ/(γ−1))] with K_D = 5th-order polynomial in equivalent cone angle 2θ_eq, K_O ≈ 1.2·offset/L, K_F = 4 f_D L/D (f_D ≈ 0.0025), K_M = 6th-order polynomial in M_SD rising steeply above M≈0.8 (Fig 5.6).
- **Sharp-lip loss** (§5.8 p.99): Fradenburgh-Wyatt NACA Rep 1193 momentum-integral closed form (5-5) + iteration (5-6); **blunt-lip correction** (5-7) with the exponential factor exp⁻¹[4.66 (r_C/Y_C)] calibrated by Barnhart against Blackaby-Watson NACA TN 3170 data.
- Normal-shock relations (5-8)-(5-13) with the motivating table of pitot recoveries (1.3→0.979, 1.6→0.895, 2.0→0.721) (pp.99-100, also p.14).
- 3D pitot inlets (§6 pp.102-109): super-elliptical capture sections, circumferentially blended lips (four-point NURBS variation), two subsonic-diffuser constructions (sequence of super-elliptical sections matched to a prescribed area distribution vs pure NURBS network), cross-comparison of linear-area / linear-Mach / linear-static-pressure area distributions (Fig 6.6 p.107; linear-Mach ≈ linear-p, both preferred for gentler initial diffusion).

### 2.6 External-compression inlet machinery (§8, pp.125-149)
- Terminal shock treated as a **normal shock at the cowl-lip station**, infinitesimally thin (EX and NS collocated) (p.33). Three real structures acknowledged: normal shock, strong oblique shock (Concorde), branched shock train (M0>2 ramjet class) (§8.3 pp.128-130, CFD illustrations Fig 8.4).
- **Nussdorfer criterion** (p.129, Nussdorfer NACA RM E51L26): terminal-shock/BL separation avoided if M_EX ≤ 1.33 (static pressure rise < 1.89); SUPIN design guideline M_EX ≤ 1.3, applied at the centerbody Mach for spikes; Kuehn data cited for tolerance of small re-attaching separations.
- **Kthrt=9 subsonic throat-section model** (§8.4 pp.131-135, the recommended external-compression throat): geometric throat just downstream of station 1; centerbody = line + NURBS shoulder + line with shoulder-radius guideline r ≈ 4·h1 (p.133); cowl interior line + NURBS; **F_cwds = explicit boundary-layer displacement accounting**: user-supplied displacement (from preliminary viscous CFD or BL estimates) linearly interpolated lip→SD→EF, an explicit low-order/CFD iteration hook (p.135).
- **Mahoney throat model Kthrt=4** (§8.5 pp.135-138) for M0 = 2-5 ramjet missiles (Mahoney, *Inlets for Supersonic Missiles*, 1990): deliberately accepts M_EX > 1.3 with a shock-train terminal shock contained in a shaped throat (circular-arc turn with r = 4h1, constant-area A_TS/A1 = 1, train-length guideline FL_thrt = 0/4/8 throat heights at M0 = 2/3/4); target recoveries from Mahoney: 0.88/0.69/0.47 at M2/3/4.
- Subsonic diffusers for spikes/2D/bifurcated ducts (§8.6 pp.139-143); entity-defined inlets incl. the Gulfstream/NASA LBSS inlet from coordinate lists (§8.7 pp.144-146); support struts (§8.9 pp.147-149).

### 2.7 Mixed-compression machinery and the MOC design core (§9, pp.150-159 + Appendix B pp.237-249)
- Geometry model Kthrt=5 (§9.1 pp.151-154): centerbody/cowl profiles in up to 4 segments; TH/TS/SD heights set either by area ratios or by specified Mach numbers through continuity (Table 9.2 p.153).
- **Kth234=2 MOC internal-diffuser design** (§9.2 pp.155-157): given the centerbody, the **cowl interior is designed by MOC**: cowl-lip deflection θ_clin creates the internal cowl shock; the shoulder is **placed at the shock impingement point and its initial slope is set to the post-shock flow angle so the shock is cancelled** (no reflection); downstream boundary condition = **prescribed linear Mach distribution along the centerbody** from the post-cancellation Mach to M_TH; the **cowl contour is extracted as the streamline ψ = ψ_ref of the MOC net** (stream-function bracketing + interpolation along each C− characteristic). Design Mach at throat M_TH ≈ 1.3 (Nussdorfer-type criterion again, §9.3 p.157). SUPIN then **re-parameterizes the MOC-computed cowl curve as a four-point NURBS** — an acknowledged lossy step with user-tunable repairs (dthcbeg/dthcend, FNcbeg/FNcend, Eqs 9-8/9-9) and inspection via the exported characteristic nets (p.157).
- Internal supersonic diffuser viscous loss (§9.6 p.159): adaptation of the Henry-based duct-loss form with the post-normal-shock Mach as the reference (9-10)/(9-11).
- **Appendix B: the MOC formulation itself** (pp.237-249) — the report's method core:
  - Steady, inviscid, adiabatic, **irrotational** supersonic flow on a planar (2D or axisymmetric) domain; characteristics dy = tan(θ±μ)dx (B-1/B-2); compatibility du = D dv + F dx on C+, du = E dv + G dx on C− with D = −tan(θ−μ), E = −tan(θ+μ), and **axisymmetric source term F = G = c²/(u²−c²)·v/y** (B-7), F=G=0 in 2D. Velocities nondimensionalized by the critical speed c* (B-8).
  - Unit problems: **field point** (B-9..B-14; averaged coefficients, fixed-point iteration, straight-segment characteristics), **boundary point** (slip condition v3 = u3 tanθ3 (B-15), closed forms B-16/B-17; both fixed-boundary and **free-boundary** variants — the free-boundary variant, closed by mass conservation/stream function, is the inverse-design workhorse), **shock point** (B-18; oblique-shock relations with iterated shock angle; C+ characteristics collapse into the strengthening shock; reference-point interpolation along C−).
  - **Stream function integration** along a C+ characteristic: axisymmetric ψ_{k+1} = ψ_k + ¼{[ρV/(M sin(μ+θ))]_k + [·]_{k+1}}(y²_{k+1}−y²_k) (B-19); 2D analog (B-20). ψ = 1 at the focal point; ψ_ref at the surface anchors all streamline-extraction design steps (B-22).
  - **Four MOC design regions**: A = isentropic external second stage (focused Mach waves, linear Mach drop at the focal point, surface = ψ_ref streamline; B.7 pp.243-245); B = last external stage to the station-1 plane (both isentropic-stage and bi-conic-shock variants; B.8 pp.245-246); C = internal diffuser from station 1 up to the cowl shock (B.9 pp.246-247); D = internal diffuser downstream of the cancelled cowl shock through TH to SD (cowl = ψ_ref streamline; B.10 pp.247-249). Nets exported as Plot3D files SUPIN.mocA/B/C/D.xyz+.q (§4.18 p.89).
  - Lineage explicitly cited (p.249): Ferri NACA Rep 841 (1946, rotational MOC), Zucrow-Hoffman Vol 1, Anderson MCF, Sorensen NASA TN D-2897 (1965), and **B.H. Anderson NASA TN D-4960 (1969) — "the MOC methods available within SUPIN are based on the methods of Reference 5"** (p.237).

### 2.8 Streamline-traced (Busemann-family) inlets (§10, pp.160-174)
- **Axisymmetric Busemann parent flowfield** (§10.2 pp.161-162): conical, isentropic compression ending in a free-standing conical shock with axial outflow; defined by (M_L, M_stex); solved by **Taylor-Maccoll equations marched upstream from the outflow with RK4**, iterating the terminal-shock angle β_stex until the leading Mach-wave angle equals π−μ_L (10-1); **truncation factor** F_strunc ∈ [0.8, 1.0] shortens the inlet at the cost of a leading-edge oblique shock (10-3/10-4); at M6 the usable truncation band collapses to 0.97-0.995 (p.168) — a quantified sensitivity.
- **ICFA-Otto-Busemann** (§10.3 pp.162-163): leading-edge deflection θ_stle < 0 spawns Mölder's Internal Conical Flowfield A (integrable only to a singular ray); matched to an upstream-integrated Busemann flowfield by **Otto's Prandtl-Meyer interface iteration** (Otto-Trefny-Slater JPP 2016); small slope discontinuity accepted. Benefit demonstrated at M4: 18% shorter inlet, cowl-exterior angle 0° vs 5°, lower wave drag (§10.7 pp.166-167, inviscid-CFD-verified).
- **2D wedge parent** (§10.4 p.163); other/numerical parents noted possible (§10.5 p.164).
- **Stream tracing** (§10.6 pp.164-166): streamlines integrated **upstream** from points on closed "tracing curves" (top/bottom super-ellipse circuits, translatable off-axis: y_stex = 0 → axisymmetric, ≈1 → scarfed STEX) placed in the parent outflow plane; each streamline is a **planar** integration by conical symmetry; capture area emerges, sized by iterating the tracing-curve scale a_st. Scarfed lip → subsonic-spillage window at the bottom lip (subsonic thickened lip over Δφ_stcl, cut-out geometry, §10.9 pp.171-173).
- Internal continuation: M_stex<1 → strong-oblique terminal shock at outflow (external-compression classification); M_stex>1 → near-constant-area internal diffuser + isolator with shock train (Kcomp=3) (§10.9 pp.169-170). BL-displacement and shoulder-rounding hooks Fr_stsh, Fx_stsh (p.170-171).

### 2.9 Bleed and bypass (§11, pp.175-188)
- Roles: BL removal at shock interactions (performance) and terminal-shock/mass-mismatch absorption (stability, unstart margin) (§11.1 pp.175-176). Magnitudes: bleed a few % of capture; bypass up to 20-30%.
- **Slater porous-bleed model** (§11.2 pp.176-179; Slater-Saunders JPP 2010, Slater JPP 2012): sonic-flow-coefficient formulation; surface-static-referenced sonic flow rate (11-5) and the **empirical 90°-hole calibration Q_sonic-B = −0.57 (p_plen/p_B)² + 0.6** (11-6), fit to data at M = 1.27/1.58/1.98/2.46, plateau (hole choking) below p_plen/p_B ≈ 0.2. Plenum treated as stagnant; **choked plenum exit** W_exit = C_D·(2-15 at exit) with M_exit = 1 (11-7/11-8), C_D ≈ 0.95. Two operating concepts: constant-plenum-pressure (controlled exit area) vs fixed-exit (iterate plenum pressure to balance inflow/outflow).
- Specification machinery (§11.3 pp.180-186): region types porous/slot/scoop/bypass; surface+interval location codes (incl. sidewall bleed aligned with the cowl shock, m=7); nine plenum-condition options; ejection Mach/angle for bleed-drag recovery; only 90° hole data are in the code (other angles ignored, p.183). Regions are **mapped onto the CFD surface grids with reported grid indices, and dedicated bleed-region grid blocks are generated** → bleed boundary conditions handed to CFD (p.186).
- **Explicit limitation** (p.187): SUPIN does **not** credit bleed with recovery improvement (only mass and drag effects).
- Shoulder bleed slot geometry + plenum, CFD-griddable (§11.4 pp.187-188; Concorde/SR-71 precedents).

### 2.10 Inlet drag bookkeeping (§12, pp.189-196)
- C_Dinlet = C_Dspillage + C_Dcowl + C_Dbleed + C_Dbypass + C_Dother (12-9); spillage = additive − lip suction (12-10); cowl = blunt-lip + wave (12-11) (p.190).
- Additive drag closed form for pitot inlets (12-12) (Sibulkin lineage).
- **Cowl-lip suction** (§12.4 pp.191-192): entirely empirical Crosthwait (General Dynamics SEG-TR-67-1, 1967) chart set digitized via IPAC: K_α, σ, effective lip angle θ_e = √(2Ω) with the curvature integral Ω (12-16..12-18), K_β, C_D2 (12-13..12-20, Fig 12.1).
- Blunt-lip drag from mean of post-normal-shock total and static pressures (12-22/12-23).
- **Cowl wave drag** (§12.6 pp.193-195): 2D exteriors by segmentwise oblique-shock/Prandtl-Meyer pressures; axisymmetric exteriors by **linearized supersonic slender-body theory**: source distribution integral (12-31), piecewise-constant f′ marching solution (12-40/12-41), closed-form Cp (12-43) — a small embedded linear-theory solver (Barnhart NASA CR-198430 lineage).
- Bleed/bypass drag = momentum-deficit forms (12-44..12-47) rewarding axial, high-Mach ejection.

### 2.11 Geometry engine (§4.15, §14.3-14.4, Appendix A, pp.83-86, 213-236)
- Component/entity system: 19 entity types (point, line, circular, ogive, ellipse, super-ellipse with Γ-function area formula (A-6), NACA 1-Series cowl profile with its 51-point table (Table A-7 p.226), polynomial, piecewise linear, cubic spline, NURBS with De Boor evaluation (A-15..A-17), four-point NURBS with tangency/attachment flags — the workhorse; cross-section entities), chained end-to-end with per-entity transformations (rotation→translation→scale→mirror, 14-1..14-3) and **time-parameterized variable-geometry schedules** (§14.4 pp.214-216; NASA Mach 2.5 VDC collapsing-centerbody example).
- **Scheduling/DOE** (§14.2 pp.210-213): one- and two-factor schedules over any input factor (discrete, range, stepwise or linearly interpolated dependence, e.g. W_C2 vs M0 mission line); outer product of schedules → arrays of design states (e.g. 3 altitudes × 7 Machs = 21 designs in one run) with per-state grids and summary-table blocks — the tool's built-in sweep/carpet-plot mechanism; there is **no internal optimizer**.

## 3. Design-iteration logic — what is iterated, what closes the design (§4.4 p.62; §4.2 p.58)

1. User specifies the design point (M0/altitude), the engine demand (one of: W2, W_C2, M2, W_cap, A_cap; Table 4.5 p.61), flow-ratio budgets (spillage, bleed, bypass, other), and the configuration factors.
2. Flow balance (2-29) gives W2/W_cap. Initial recovery estimate = **MIL-E-5007E correlation** (3-5).
3. **Fixed-point iteration**: perform the aerodynamic analysis of each inlet component in sequence (approach flow → external diffuser stage shocks/MOC → terminal shock → throat-section losses → subsonic-diffuser correlation), recompute total recovery and inlet flow rate, resize, repeat until recovery and flow rate converge. In design mode the converged unknown is the **reference capture area A_cap** (the inlet is sized to feed the engine); if A_cap is imposed instead (KWinp=5), the iteration converges on pt2/ptL. No convergence tolerance is stated in the text.
4. Inner iterations inside a pass: θ-β-M closed-form (none), Taylor-Maccoll shock-angle iteration, Busemann terminal-shock-angle iteration, Oswatitsch carpet search over ramp angles (2D), M_tw iteration to hit the specified diffuser-exit match (Kmtexd), MOC fixed-point iterations per unit problem, tracing-curve scale iteration for STEX capture area, plenum-pressure balance iteration for fixed-exit bleed.
5. What closes the design: focal-point/shock-on-lip condition (or prescribed supersonic spillage) fixes the external diffuser ↔ cowl lip relation; M_EX ≤ 1.3 guideline fixes the external compression amount; M_TH ≈ 1.3 and shock cancellation fix the internal diffuser; area/Mach specifications + continuity (2-31/2-32) fix TH/SD/EF areas; the subsonic diffuser NURBS + loss model fix the rest. After execution SUPIN writes `SUPIN.new.in` with all derived factors filled in — the restart/refinement mechanism (p.58).

## 4. Grid generation and CFD hand-off (§13, pp.197-209; §4.18 pp.88-89; §11.3 p.186)

- **Surface grids**: structured quads on every component, spacing controls (Δs_beg/end/max, max ratio R_gsmax ≤ ~1.2, Eq 13-1), uniform/geometric/tanh distributions; outputs SUPIN.xyz (Plot3D, starboard half), Solid.xyz (both halves), STL (§13.1-13.2 pp.197-199).
- **CFD grids**: automated **multi-block structured** grids, planar (2D/axisym) or 3D, one Plot3D file per sub-domain: cowl lip (8-block C-to-H topology sized by d_dclp), cowl exterior, farfield, cowl interior, forebody, throat, inner core (deliberately **non-point-matched** interfaces for the streamline-traced inner region, Fig 13.8 p.205), subsonic diffuser, spinner (C-grid + singular-axis block), bleed-slot+plenum (20 blocks), struts (28 blocks), bleed-region BC blocks, sidewall blocks (§13.3 pp.199-201). Wall spacing Fdswall (e.g. 2e-5 ft) for BL resolution; global refinement factor Fgds for grid-convergence studies (§13.4 pp.201-203). No unstructured grids (surface grids can seed external mesher).
- **Outflow-nozzle sub-domain — the flow-rate boundary-condition device** (§13.5 pp.203-208): a constant-area settling duct (length d_dnoz·D_ref, 1.0 nominal, 1.5-2.0 if separation must reattach) + converging-diverging nozzle appended behind the engine face; the **choked throat (D_noz = F_gnoz·D_EF, 13-5) sets W2 by continuity (13-6)**, and the diverging section accelerates to M_nex ≈ 1.25 (A_nex = 1.047 A_noz) so a supersonic-extrapolation outflow BC applies with zero upstream influence. F_gnoz is swept in CFD to back-pressure the inlet and trace the cane curve. Converging/diverging lengths 0.65/0.75·(D_EF−D_hub) are admitted to have "no solid aerodynamic basis" beyond CFD experience (p.207). I-planes ⊥ axis enable flow-rate integration per plane and a statistical convergence measure of W2 (p.208).

## 6. Fidelity ledger — derived vs empirical vs heuristic (with sources)

**Derived (exact within inviscid/calorically-perfect assumptions)**
- Isentropic/normal/oblique shock relations; closed-form θ-β-M cubic solution (7-2..7-7). Taylor-Maccoll ODE + RK4 (7-8..7-17). Prandtl-Meyer (7-18..7-20). MOC characteristic/compatibility system incl. axisymmetric source term (B-1..B-22). Busemann/ICFA conical flowfields (10-1..10-4). Continuity/flow-balance algebra (2-15..2-32). Additive drag (12-12). Bleed/bypass momentum drag (12-44..12-47). Slender-body wave drag = linearized theory (12-30..12-43). Oswatitsch equal-loss stage criterion (proved optimal in the cited source; imposed by search).
- Thermally-perfect cp(T): statistical-mechanics harmonic oscillator, Θ = 5500 °R (2-12..2-14).

**Empirical correlations (calibrated to named data)**
- MIL-E-5007E recovery schedule (3-5), 1<M<5 exponent 1.35, coefficient 0.075; M>5 form 800/(M⁴+935). Source: military spec (1983). Role: initial guess + generic benchmark.
- Subsonic-diffuser loss (5-3): Henry-Wood-Wilbur NACA RM L56F05 data via IPAC (Barnhart CR-204130); K_D (5th-order poly), K_M (6th-order poly), K_O = 1.2·offset ratio, K_F with f_D = 0.0025.
- Sharp-lip loss: Fradenburgh-Wyatt NACA Rep 1193 momentum balance (semi-analytic); blunt-lip damping constant 4.66 calibrated to Blackaby-Watson NACA TN 3170.
- Porous-bleed sonic-flow coefficient: Q = −0.57(p_plen/p_B)² + 0.6 for 90° holes, calibrated at M 1.27-2.46 (Slater JPP 2012); C_Dexit ≈ 0.95.
- Cowl-lip suction: Crosthwait SEG-TR-67-1 digitized chart quadruple (K_α, σ, K_β, C_D2).
- Nussdorfer separation threshold M ≤ 1.33 / p-rise 1.89 (NACA RM E51L26), used as the M_EX ≤ 1.3 and M_TH ≈ 1.3 design pins.
- Mahoney shock-train containment lengths (0/4/8 h1 at M 2/3/4) and recoveries (0.88/0.69/0.47) — handbook empiricism (Mahoney 1990).
- US Standard Atmosphere curve fits; hot/cold/tropical day profiles.

**Heuristics / conventions (declared, no data basis claimed)**
- Shoulder radius ≈ 4×duct height (pp.133, 136). Interior NURBS control points at 1/3 spacing (default throughout). Terminal shock = normal shock at a station (external: at lip; mixed: at TH) — structure-free surrogate for trains/oblique systems. Linear Mach BC along centerbody in MOC region D; linear Mach drop at the focal point in region A. Outflow-nozzle lengths 0.65/0.75·(D_EF−D_hub) ("no solid aerodynamic basis", p.207); A_nex = 1.047·A_noz → M ≈ 1.25. F_cwds/Fr_stsh BL displacement = user-fed linear allowances. θ_clex = θ_clin + 3-5° structural margin. Equivalent-cone-angle 5° default for subsonic diffuser length. Bleed porosity default 0.4.

## 7. Stated limitations (the report's own)

- Analysis mode (Kmode=3) not fully functional (p.59, red). Angle-of-attack/sideslip models absent — α0, β0 forced to zero (p.63, red). Many DataID blocks / components / entities are placeholders (App I p.283, p.288: capture-cross-section block, vortex generators, sidewall geometry, auxiliary intake, 3D engine face, TFI/NURBS surfaces, several component types).
- Terminal shock modeled as a normal shock; **no shock-train loss model** (pp.33, 129-130, 157-158). No viscous loss on the external supersonic diffuser (p.123). No recovery credit for bleed (p.187). Bleed data limited to 90° holes (p.183). No blunt-lip shock-standoff model in design (p.128; Moeckel model only as a unit-problem calculator, p.282).
- Quasi-1D uniform-station assumption acknowledged as inapplicable inside the wave-dominated segments (§2.4 p.29). MOC-designed cowl re-parameterized by NURBS with acknowledged deviation needing manual repair (pp.157, 267). No internal optimizer; scheduling only. No distortion prediction. Isolated-inlet scope: representative cowl exterior only, no airframe integration (p.71). Calorically-perfect γ=1.4 in practice; M ≤ 5-6 envelope by dissociation avoidance (pp.7, 26-28). Empirical diffuser-loss model can misfire for unconventional ducts (3D pitot case, p.254, with the user-override escape). SUPIN not intended to certify absolute performance: the pattern is design → geometry/grids → CFD verification.

## 8. CONNECTIONS to the host program (cycle-averaged variational RDE nozzle)

Candidate connections, each with what/where/why; anti-connections at the end. (Flags only — adjudication belongs to the program.)

**C1 — Axisymmetric MoC formulation cross-check (STRONG).** Appendix B (pp.237-249) is an independently documented axisymmetric irrotational MoC: characteristic slopes, compatibility with the axisymmetric source term F = G = c²/(u²−c²)·v/y (B-7), critical-speed nondimensionalization (B-8), averaged-coefficient fixed-point unit problems, shock points with C+ collapse. The program's certified MoC engine can use B-1..B-18 as an external cross-check of its own compatibility relations and unit-problem discretization (SUPIN's is first-order-averaged, straight-segment — a useful *lower* bar and a source of test cases: the M3 mixed-comp nets of E.1/E.2 with quoted ptTH/pt0 to 4 digits vs inviscid CFD). Caveat worth noting in any cross-check: SUPIN's MoC is **irrotational** even downstream of curved conical shocks (entropy gradients dropped), whereas the program's stratified-inflow machinery (s(ψ), h0(ψ)) is exactly the rotational generalization SUPIN lacks — Ferri NACA Rep 841 is cited (p.249) but not implemented. This is a genuine capability differentiator to cite, not to copy.

**C2 — Stream-function-based inverse design = the program's streamline transport, mirrored (STRONG).** SUPIN's design moves (isentropic external stage B.7; cowl interior as the ψ_ref streamline B.10; upstream stream tracing through Busemann parents §10.6) all reduce to: prescribe a boundary data distribution (linear Mach along a wall or at a focal point), solve the MoC net, extract a streamline by stream-function bracketing (B-19/B-20/B-22). This is the inlet-side dual of Rao-type nozzle design (prescribe control-surface data, extract the wall as a streamline). Two importable specifics: (a) the *focal-point family* as a design handle (all waves through one point, offset as a robustness margin — Kfocal options, §7.4-7.5), (b) the truncation-factor sensitivity result (F_strunc band collapsing to 0.97-0.995 at M6, p.168) as a template for reporting design-space shrinkage. Also a cautionary precedent: re-parameterizing an MoC-exact contour by a low-order NURBS demonstrably breaks shock cancellation and needs manual repair (pp.157, 267) — the program's policy of carrying the MoC contour itself (or a certified interpolant with error bars) is vindicated by this documented failure mode.

**C3 — Design-tool architecture lessons for productization (STRONG, architectural).** The SUPIN pattern worth emulating: (i) strict factor-based input with a declared quick-reference (App I) and *red-flagged non-functional options* — honest capability surface; (ii) `SUPIN.new.in` write-back of derived factors = restartable fixed-point design loop; (iii) product decomposition of recovery per component with per-segment user overrides (Fptseg*, Fpt2ptSD) — every empirical closure is bypassable by the user, which is exactly the escape used when the model misfired (p.254); (iv) scheduling (one/two-factor, outer product) as the sweep mechanism instead of an embedded optimizer; (v) every claim shipped with sample cases (input+output+grids) that double as regression tests; (vi) explicit unit-problem mode exposing the elementary calculators. Anti-pattern to avoid: no stated convergence tolerances for the master fixed-point loop, no error bars on the empirical closures — the program's certificate/oracle discipline goes strictly beyond SUPIN's state of practice.

**C4 — CFD hand-off / data-contract parallels for phase F5 (STRONG).** §13 is a complete worked example of a low-order-tool→CFD data contract: multi-block structured grids per sub-domain, solver-specific BC files (gman/cfsplit for Wind-US), bleed regions delivered as grid-index ranges + dedicated blocks, MOC nets exported as Plot3D grid+solution for inspection, and above all the **outflow-nozzle sub-domain** (§13.5): impose the flow-rate BC through a *physical* choked throat placed far from the plane of interest, then sweep the throat area to trace the operating curve — a device directly transplantable to RDE-nozzle CFD verification (imposing the mass-flow/back-pressure side of the contract without contaminating the engine-face/interface plane; the plane-by-plane flow-rate statistics of p.208 are a ready-made convergence oracle). The BL-displacement hooks (F_cwds, Fr_stsh: user-fed displacement thickness from preliminary viscous CFD, linearly distributed) are a minimal inviscid↔viscous iteration contract worth comparing with the program's corrector scoping.

**C5 — Inlet-side system context for air-breathing RDEs (MODERATE).** For any air-breathing RDE system framing: the inlet delivers pt2/ptL with the cane-curve operating structure (§3.2), stability margins (buzz/unstart), and mass-capture bookkeeping (2-27..2-29). Two contract-relevant facts: turbojet/turbofan vs ramjet throttle response have *opposite* engine-face static-pressure trends (p.9) — an RDE's back-pressure signature (periodic, with its own mean shift) determines where it sits on the inlet's characteristic curve; and the terminal-shock position tolerance (subcritical margin, bleed absorption §11.1) is the inlet-side analog of the program's interface-data periodic-wave scope pin: an RDE feeding back pressure oscillations into a mixed-compression inlet threatens unstart — the isolator/shock-train section (§2.5.5, Kcomp=3) is the classical buffering answer and would be the natural coupling element in any RDE-inlet study. MIL-E-5007E (3-5) supplies the standard recovery-vs-Mach budget for system-level cycle numbers.
- Also: the Nussdorfer M ≤ 1.3 pin and the Mahoney shock-train containment lengths are the kind of "empirical pin with named source + falsifier data" the program's ledger discipline wants when/if inlet-side assumptions enter system analyses.

**C6 — Taylor-Maccoll / Busemann machinery as oracle sources (MODERATE).** SUPIN's unit-problem mode and the STEX appendix give independently computed conical-flow and Busemann numbers (e.g., M4 Busemann inlet recovery 0.9192 SUPIN vs 0.9435 inviscid CFD, Table G-3 p.279; cone/normal-shock/PM tables Km03-Km08 p.281-282). If the program ever needs external oracle values for conical or focused-compression flows (e.g., testing the MoC engine on a Busemann-like focused-wave field, which stresses characteristic coalescence), this TM + its distributed sample cases are a citable source.

**Anti-connections (superficially relevant, adjudged not load-bearing)**
- **The empirical loss/drag stack** (subsonic-diffuser polynomial correlation, Crosthwait lip-suction charts, MIL recovery, bleed coefficient): inlet-specific, subsonic-diffuser-specific calibration envelopes; nothing transfers to nozzle-side physics. Value is methodological only (ledger discipline, override design), covered in C3.
- **Geometry entity catalog** (App A): standard CAD-curve machinery (NURBS/De Boor, super-ellipses); the program has no gap here; only the documented NURBS-vs-MOC-contour failure (C2) is load-bearing.
- **Distortion metrics** (§3.4): engine-face rake conventions for turbomachinery compatibility; no RDE-nozzle analog at the current program scope.
- **Variable-geometry scheduling** (§14.4): mechanism-kinematics bookkeeping for translating spikes; out of program scope.
- **Thermally-perfect single-Θ cp(T)** (2-12): strictly weaker than the program's tabulated Cantera-backed thermo; not a source, just a sanity benchmark at low temperature.
- **"Design tool with CFD-free core" as a rigor benchmark**: SUPIN's accuracy claims rest on CFD comparisons *without stated tolerances or rejectors*; it is an architectural benchmark (C3, C4), not a rigor benchmark — the program's certificate standard is not anticipated anywhere in the TM.
